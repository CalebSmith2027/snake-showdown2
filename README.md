# Snake Showdown 🐍

Cartoon Snake vs CPU, plus online Free-For-All multiplayer with private room codes.

Play: open the site, click **Multiplayer FFA**, then **Create room** and share the 5-letter code
(or the invite link). Friends enter the code to join the same lobby.

Controls: W A S D to move, hold P to sprint, M to mute.

Multiplayer uses WebRTC through the free PeerJS Cloud. The host's browser runs the game.
